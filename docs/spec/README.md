# Specifikace / Specification

Spustitelná specifikace je anglická, ve [`features/`](../../features/).
Soubory v [`cs/`](cs/) ji česky zrcadlí jeden k jednomu, se stejnými `@id`
a stejnými scénáři. Spouštět se nemusí, musí ale být vždy v souladu:
měňte obě verze ve stejném commitu.

The executable specification is the English one, in
[`features/`](../../features/). The files in [`cs/`](cs/) mirror it in Czech,
one for one, with the same `@id`s and scenarios. They aren't executed, but they
must always be in sync: change both in the same commit.
